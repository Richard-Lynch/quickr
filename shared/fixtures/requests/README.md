# Request goldens

What the iOS client sends, generated by Swift and checked by the backend: the
reverse of `../api/`. **Never edit these by hand.**

| Generator                                                                                                                  | Checked by                                                                                           |
| -------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| `ios/QuickrKit/Tests/QuickrDataTests/API/RequestGoldenTests.swift` (the real `APIClient`, captured from a `FakeTransport`) | Swift drift check; `backend/tests/test_request_goldens.py` (Pydantic models, replay through the app) |

Regenerate with
`QUICKR_UPDATE_VECTORS=1 swift test --package-path ios/QuickrKit --filter RequestGolden`
(it writes the files and removes stale ones); without the variable the test
fails when a committed file differs. Review the diff: it is a change to what
goes on the wire.

One file per request, named `<operationId>[.<variant>].json`, in the backend's
`dump_json` layout:

```json
{
  "operation_id": "createEntry",
  "request": {
    "method": "POST",
    "path": "/api/v1/topics/33333333-…/entries",
    "headers": { "x-quickr-channel": "ios", "x-quickr-expect-epoch": "…" },
    "body": {}
  }
}
```

`headers` holds every header the client sets (lowercased), without Access
credentials. A request without a body has `"body": null`.

Ids and the identity are placeholders that the pytest replay swaps for real
values: server `11111111-…`, epoch `22222222-…`, topic `33333333-…` (the id of
the topic the `createTopic` golden creates), entries `44444444-…-00000000000n`.
Replayed unchanged, every mutation must get 409 `server_mismatch`; with the real
values, the status in `EXPECTED` in the pytest module.

Every mutating or request-bodied operation needs at least one golden: Swift
(`everyMutationAndBodiedOperationHasAGolden`) and pytest
(`test_every_mutation_has_a_golden`) both check it.
