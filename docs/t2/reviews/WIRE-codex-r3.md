1. **P2 — Older entries lose their answer summaries.** [TopicTile.tsx](/Users/richie/code/quickr-worktrees/t2-wire/frontend/src/components/topics/TopicTile.tsx:141) passes an empty question list whenever the latest entry predates the current version. After a publish, an untimed entry with answers therefore falls back to the entry count, while a timed entry shows only its timing. The summary algorithm requires the entry’s version’s questions. The quick-answer fallback can also label an old answer using the current question definition.

2. **P2 — An unrelated older run can hide Resume for the current version.** [TopicTile.tsx](/Users/richie/code/quickr-worktrees/t2-wire/frontend/src/components/topics/TopicTile.tsx:115) selects the versions query whenever *any* local run is on an older version, then passes that query’s data instead of the known current context. If the versions query fails or has a still-fresh cached list from before a publish, a latest stop on the current version cannot resolve its context, so Resume disappears. Select the candidate’s version and retain the current context when that candidate is current.
