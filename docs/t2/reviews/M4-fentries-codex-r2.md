- **[P2] Historical summaries use the wrong questions when versions are unavailable** — [EntriesPage.tsx:67](/Users/richie/code/quickr-worktrees/t2-m4-fentries/frontend/src/pages/topic/EntriesPage.tsx:67). Until the versions request succeeds—and indefinitely if it fails or the app is offline—the fallback uses current questions for every entry. An older entry can therefore show current labels, omit removed answers, or assign a queued answer the wrong type. A type change can also cause a render error: an old multi-select array assigned the current `str` type reaches `collapseWhitespace`, which calls `.replace` on the array. Use the entry’s versioned questions from a reliable cache or stored snapshot; when they are unavailable, avoid passing mismatched values to the summary. Add coverage for a failed or pending versions request with an older queued entry whose question was removed or changed type.
