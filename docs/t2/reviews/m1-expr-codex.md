- **P2 — Syntax lookahead can report a later character instead of the offending token.** [timer_expr.py](/Users/richie/code/quickr-worktrees/t2-m1-expr/backend/app/services/timer_expr.py:154) lexes the next token completely while consuming the previous one. - **P2 — The unit-suffix clarification conflicts with longest-first token matching.** [timer_expr.py](/Users/richie/code/quickr-worktrees/t2-m1-expr/backend/app/services/timer_expr.py:112) consumes *all* letters after a number as a unit, and [the vector](/Users/richie/code/quickr-worktrees/t2-m1-expr/shared/fixtures/timer-expr-vectors.json:55) pins `30sec` as `syntax` at **2**. - **P2 — The shared vectors do not exercise the double-precision requirement at a rounding boundary.** [test_timer_expr_vectors.py](/Users/richie/code/quickr-worktrees/t2-m1-expr/backend/tests/test_timer_expr_vectors.py:28) includes division and fractional durations, but none distinguish binary-double evaluation from plausible decimal arithmetic or intermediate rounding.
