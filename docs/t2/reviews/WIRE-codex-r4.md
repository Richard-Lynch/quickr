1. **P2 — Older entries lose their answer summaries.** [TopicTile.tsx](/Users/richie/code/quickr-worktrees/t2-wire/frontend/src/components/topics/TopicTile.tsx:150) passes no questions when the latest entry predates the current version. After a publish, untimed entries fall back to the count and timed entries show only timing, even when their answers have displayable summaries. The summary specification calls for the entry’s version’s questions; the same limitation exists on the iOS tile and widget.

2. **P2 — Widgets can label an old answer using the current question.** [WidgetViews.swift](/Users/richie/code/quickr-worktrees/t2-wire/ios/QuickrKit/Sources/QuickrUI/Widgets/WidgetViews.swift:222) falls back to `lastAnswer` when an older untimed entry has no summary. `WidgetReader` obtains that answer by the current question’s key, so a publish that changes its options or unit can make the widget display an incorrect “Last …” value. The final iOS tile fix guards this case, but the widget fallback remains unguarded.
