1. **P2 — Resume disappears after a topic version is published.** [TopicTile.tsx](/Users/richie/code/quickr-worktrees/t2-wire/frontend/src/components/topics/TopicTile.tsx:100) supplies `useReopenOffer` with only the current version. The offer resolves its context using the stopped entry’s version, so a resumable run pinned to an earlier version no longer gets a Resume button after a publish. Fetch or retain the stopped run’s version when it differs from the current version, and add a test covering a stop followed by a publish.

2. **P2 — Older entries can receive the wrong lap labels.** [TopicTile.tsx](/Users/richie/code/quickr-worktrees/t2-wire/frontend/src/components/topics/TopicTile.tsx:194), [TopicTile.swift](/Users/richie/code/quickr-worktrees/t2-wire/ios/App/Home/Tiles/TopicTile.swift:237), and [WidgetTopic.swift](/Users/richie/code/quickr-worktrees/t2-wire/ios/QuickrKit/Sources/QuickrCore/Widgets/WidgetTopic.swift:51) suppress current-version questions for an older entry but still pass the current timer. If a lap type’s label or order changed, the summary describes the old run using the new definition. Use the entry’s pinned timer when available; otherwise pass no timer for a version mismatch so the summary falls back to stored lap keys. Test renamed lap types on all three surfaces.

3. **P2 — Widget summaries can remain stale after an entry-only edit.** [WidgetReloader.swift](/Users/richie/code/quickr-worktrees/t2-wire/ios/App/Widgets/WidgetReloader.swift:43) observes topics, outbox, sync state, and runs, but not entries. Adding `lastSummary` to the fingerprint only detects a change when a check runs; an edit to a synced entry that leaves those observed values unchanged can leave the widget showing its previous summary. Observe entry-table changes as another reload trigger and test an answer edit that leaves the topic’s count and timestamp unchanged.

4. **P3 — Archived PWA tiles never load answer labels for their summaries.** [TopicTile.tsx](/Users/richie/code/quickr-worktrees/t2-wire/frontend/src/components/topics/TopicTile.tsx:90) disables the detail query for archived topics, while the new summary needs those details for questions. Consequently, an archived untimed topic with entries shows only its count even when its latest entry has a displayable summary. Enable the detail query for archived tiles with entries, and cover the archived filter in the tile tests.
