### Mutation checks (each restored from a copy)

1. iOS: drop `appearance:` at the local LA start →
   `startCarriesTheTopicsAppearance` fails
   (`activity.attributes.appearance == topic.appearance`).
2. iOS: `TopicChrome.primaryFill` ignores the theme →
   `aColouredThemeFillsWithItsTint` fails.
3. PWA: drop `tag` from the `listTopics` query → both "the tag filter" tests
   fail.
4. PWA: drop `style={topicStyle(t.appearance)}` on the tile → "a coloured idle
   tile" fails.
5. PWA: Resume with the current version only → "a stop on an older version"
   fails.
6. PWA: archived details disabled → "an archived tile's summary line" fails.
7. PWA: no local-run check for an older version → "a queued stop of a run on an
   older version" fails.
