# M1 gate runs

Runs on `t2/m1` at `4eac3ef6` (every M1 WP merged), on 2026-11-26, from the
worktree `quickr-worktrees/t2-m1-gate`. Each xcresult is exported to
`xcresults/<name>-summary.json` (`xcresulttool get test-results summary`) and
`xcresults/<name>-tests.json` (`xcresulttool get test-results tests`).

The tests exports are slimmed so they're small enough to commit. Each passed
Swift Testing `Arguments` node is folded into an `argumentRunsPassed` count on
its test case, and `nodeIdentifierURL` and the `duration` string are dropped
(`durationInSeconds` stays). Every test case, every failed or skipped node and
every message is kept as exported. There are no attachments.

Simulators: this worktree's clones `quickR iOS-26-0 t2-m1-gate-f08e14`
(`37467AE0-F858-45C0-BA28-431CF163C24C`, iPhone 17, iOS 26.0) and
`quickR iOS27 t2-m1-gate-f08e14` (`EBDB3CEF-02BD-410D-A9D4-FCB0CE6C50E4`, iPhone
17, iOS 27.0). No base devices were used. Each clone was shut down after its
run.
